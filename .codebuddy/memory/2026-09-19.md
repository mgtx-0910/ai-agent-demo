## 经验记录

- Apipost MCP 的 `openapi` 参数必须是「不含任何转义字符」的 JSON：description 里不要写 `\n`，字符串内不要出现被转义的双引号，直接传缩进格式的 JSON 对象最稳；否则统一报 `arguments must be a valid JSON string`
- 给 query 参数写了 `example` 时，同步后的接口 URL 会把示例值拼进 query（如 `/documents?title=入职&categoryId=20001&...`），属正常行为，需要干净 URL 可在 Apipost 里手动清空
